# Security operations runbook
 
1. Enroll controllers using hardware-backed identity and short-lived bootstrap authorization.
2. Establish the OOB channel before applying the first mesh firewall policy.
3. Deploy default-deny zones and verify the control-plane canary.
4. Add relays and egress gateways in at least two failure domains.
5. Enroll application nodes through BAPC Cloud & Deployment™ before workloads become reachable.
6. Enable Diagnostics™ signed containment and clearance events.
7. Verify JIT approval, expiry and forced termination.
8. Exercise quarantine, forensic-only access and restoration in staging.
9. Test controller loss, relay loss, egress failover and OOB rollback.
10. Run the Universal Final Audit before any production activation.
 
Emergency lockdown requires verified high-tier breach status, owner authorization, OOB health confirmation, a recorded recovery plan and continuous audit capture.
